Prosjekt 01

Solaris

IN2000 · Software development · Team-arbeid

Mange norske boligeiere vet ikke om solcellepaneler faktisk lønner seg for akkurat deres eiendom. Som Systemutvikler og UX-designer i et tverrfagelig team var jeg med på å utvikle en Android-app som gir et personlig estimat på lønnsomhet basert på adresse, tak-areal og historiske værdata. Løsningen ble testet med ekte brukere gjennom flere runder bruker- og geriljatest.

Prosjektet var en del av faget IN2000: Software Engineering med prosjektarbeid. Appen er bygget i Kotlin og henter data fra Meteorologisk institutts Frost API og PVGIS for å beregne solinnstråling, estimert produksjon og potensiell strømsparing. Vi jobbet tverrfaglig med Scrumban som rammeverk, og en prosess som inkluderte brukerintervjuer, wireframing i Figma og flere runder med bruker- og geriljatest for å sikre at løsningen traff målgruppen.

BO - Bottle

Designtenking · Datainnsamling · Brukertesting

Med fokus på friluftslivs glade mennesker ønsket vi å addressere utfordringen med dårlig ventilering i telt om sommeren. Som UX-designer i team designet vi The BOB (BoxOffice-Bottle), en lettvekt, sammenleggbar vifte med innebygd CO2-sensor som automatisk justerer luftsrømmen i teltet.

Produktet er bygget med Arduino og har et design og utforming som ble støpt gjennom solid brukermedvirknign. Prosessen fulgte Double Diamond, med brukerinvolvering gjennom hele løpet, inkludert innledende intervjuer og fokusgrupper til workshops med Crazy-8 og Six Thinking Hats, og avsluttende brukertest.

Selv om jeg bidro på tvers av hele prosessen, hadde jeg ekstra fokuset på å sikre tilstrekkelig divergent tenkning i hver fase, fra overordnede konseptvalg til konkrete designbeslutninger som oppheng og bruksmodus. Jeg passet på at løsningsrommet ble utforsket bredt nok før teamet konvergerte mot en retning.

Creating Screen Interfaces

Griffith University · UX · Interaksjonsdesign

I faget Creating Screen Interfaces ved Griffith University gjorde vi et dypdykk i digitale brukergrensesnitt. Fokus gikk utover å lage visuelt tiltalende nettsider, og handlet i stedet om hvordan man designer løsninger som er tilpasset brukernes oppgaver og behov. Samtidig utforsket vi hvordan man kan opprettholde god brukskvalitet mens man utfordrer etablerte konvensjoner.

Vi jobbet med standarder for nettsideoppsett, og så på likheter og forskjeller mellom multi-page- og scroll-baserte løsninger. Gjennom ulike oppgaver undersøkte vi også hvordan innhold som for eksempel oppskrifter, kan tilpasses spesifikke brukssituasjoner og målgrupper, og hvordan slike formater kan redefineres.

Faget inkluderte åpne, eksperimentelle oppgaver der vi utforsket nye måter å bruke digitale medier på, blant annet ved å teste grensene for hvordan tidslinjer og informasjonsflyt kan designes.
